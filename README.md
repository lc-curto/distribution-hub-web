# Cosmetics Hub Web

Frontend React do Cosmetics Hub, independente da API FastAPI.

## Requisitos

- Node.js 22
- pnpm 9

## Desenvolvimento

```bash
pnpm install
pnpm dev
```

A API local deve estar disponível em `http://localhost:8000`; configure `VITE_API_URL` conforme necessário. A documentação comum do produto e da API ficará no repositório `cosmetics-hub-api`, em `docs/`.

## Validação

```bash
pnpm build
```
